# Cómo usar Grok LIFE OS

1. Clona https://github.com/bubacnth1998-source/grok-life-os
2. En Linux del Chromebook:
   ```
   pip install -r requirements.txt
   export PYTHONPATH="${PWD}/backend"
   ./scripts/start.sh
   ```
3. Chrome: http://127.0.0.1:8000
4. Crea cuenta o usa la que registres
5. Módulos en la barra: Core, Finance, Projects, Time, Life, Memory, Sim, Audit, Nexus

API docs: http://127.0.0.1:8000/api/docs
